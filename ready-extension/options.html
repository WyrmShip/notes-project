Quick Notes — Settings

Send captures to

Both = every capture goes to the cloud dashboard AND the Firebase backup. If one is unreachable, the other keeps receiving everything.

Notes workspace sync

Enter your key (like theone1) just once and press Save — it is stored forever and never shown or asked for again. Notes sync automatically and silently in the background; nothing else to configure.

Page scope

Only-sites mode syncs notes from the listed sites (subdomains included). Except mode skips the listed sites — add your personal ones there.

Firebase backup dashboard

The sync user is created once in Firebase console → Authentication → Sign-in method (enable Email/Password) → Users → Add user. Rules must allow authenticated writes to /captures.
